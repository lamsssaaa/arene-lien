# arene-lien

Page de redirection vers **Paper Arena**, un jeu de trading 100 % virtuel
qui tourne sur une machine personnelle derrière un tunnel Cloudflare.

L'adresse du tunnel change à chaque redémarrage ; ce dépôt existe pour
donner aux joueurs **une adresse stable** à mettre en favori. Le fichier
`index.html` est réécrit automatiquement par `scripts/go-live-local.sh`.

Rien d'autre n'est publié ici : aucune donnée de jeu, aucun compte, aucun
identifiant. Ce dépôt ne contient qu'une redirection.
